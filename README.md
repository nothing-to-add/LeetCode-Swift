# LeetCode Solutions in Swift 🚀

A collection of my solutions to [LeetCode](https://leetcode.com/) problems, written in **Swift**.

This repository serves as a personal archive of problem-solving practice, algorithm/data structure exploration, and Swift language experimentation.

## 📂 Structure

Each problem is stored as a separate Swift file, named after the problem number and title, for example:

## ✅ Progress

| # | Title | Difficulty | Solution |
|---|-------|------------|----------|
| 1 | Two Sum | Easy | [1-two-sum.swift](./1-two-sum.swift) |

> This table is updated as new solutions are added.

## 🛠 Approach

Each solution aims to be:
- **Correct** — passes LeetCode's test cases
- **Readable** — clear variable names and structure
- **Efficient** — reasonable time/space complexity, with notes when trade-offs are made

Where useful, solutions include comments explaining the algorithm/approach and its time & space complexity.

## 🚀 Running Solutions Locally

Each file can be compiled and run individually using the Swift toolchain:

```bash
swift run <filename>.swift
```

Or open the file in Xcode / a Swift Playground to test manually.
